# Mi eBird Personal v5.5

Aplicación personal para controlar especies nativas observadas y pendientes, revisar avistamientos y preparar rutas viales regionales a partir de registros recientes, usando taxonomía y nombres comunes oficiales de eBird (`es_CL`).

## Funciones principales

- Excluye especies naturalizadas, exóticas provisionales, escapes y taxones domésticos.
- Resuelve región y comuna/distrito desde las coordenadas cuando eBird o el CSV no las informan.
- Permite ordenar todas las tablas haciendo clic en sus cabeceras.
- Agrupa las oportunidades por país, región, comuna o hotspot.
- Calcula una ruta independiente para cada región seleccionada.
- Optimiza cada recorrido por tiempo y distancia vial entre los sitios.

## Servicios

- eBird API 2.0: taxonomía, catálogos, regiones, hotspots y observaciones recientes.
- OSRM / OpenStreetMap: matrices, tiempos, distancias y geometrías viales.
- Nominatim / OpenStreetMap: geocodificación inversa de coordenadas faltantes.
